# AdPrompt Studio — A/B 实验设计（D10 定稿）

> 方法论：product-experimentation（假设拆解 / 三类指标 / 样本量 MDE / 诚实归因）
> 状态：**Owner 已拍板**（2026-08-19），进入执行（D11）

---

## 一、实验假设

**策略对比**：「质检后自动重写」 vs 「仅手动提示」

| 组 | 处理 | 说明 |
|---|---|---|
| A 对照组 | 生成 → 质检打分 → 直接展示 + 提示"可手动修改" | 现状基线 |
| B 实验组 | 生成 → 质检打分 → **低分自动重写 2 轮** → 展示 | 干预变量 |

**假设**：自动重写 → 结果质量更高 → 更多用户复制（质检通过后复制率提升）
**方向**：B 组质检通过后复制率 > A 组

## 二、指标（三类）

| 类型 | 指标 | 定义 |
|---|---|---|
| **主指标** | 质检通过后复制率 | 复制人数 / 质检通过人数 |
| 辅助指标 | 质检通过率 | 质检通过 / 生成成功（理解"为什么"） |
| 辅助指标 | 平均生成耗时 | 理解"成本" |
| **护栏** | 单次生成成本 | ≤ ¥0.1/次（Owner 拍板），超限 → 策略否决 |

## 三、分组与样本

- **随机单元**：模拟用户（干预发生时刻分配）
- **分组**：50/50 随机（Owner 拍板）
- **样本量**：800 用户（Owner 拍板），每组 400

**样本量核验（MDE）**：
基线复制率 ~57%（D8 漏斗实测），目标检测 +10pp（57%→67%）：
```
n ≈ 8 × [0.57×0.43 + 0.67×0.33] / 0.10²
  ≈ 8 × (0.245 + 0.221) / 0.01
  ≈ 373 人/组
```
每组 400 > 373，**达到最小可检测效应需求**（α=0.05，power=80%）。

**⚠️ 诚实声明**：即使满足样本量公式，数据仍是模拟的（is_simulated=1），结论只标「方向性」+ 样本局限。真实验证需真实用户（2-3 朋友试用 + 后续迭代）。

## 四、执行流程

1. 生成 800 模拟用户，随机标记 `ab_group=A|B`
2. A 组：走「质检打分→展示」路径（复用现有工作流）
3. B 组：走「质检打分→低分自动重写（≤2 轮）→展示」路径（新增重写逻辑）
4. 记录每组的：质检通过人数、复制人数、生成失败数、估算成本
5. 计算两组主指标对比 + 显著性（两比例 z 检验）+ 护栏检查

## 五、决策规则

| 情况 | 决策 |
|---|---|
| 主指标显著提升 + 护栏不恶化 | 支持假设（方向性） |
| 主指标无显著差异 + 护栏恶化 | 否决（成本超限） |
| 主指标显著提升 + 护栏恶化 | **否决**（护栏优先，方法论铁律） |
