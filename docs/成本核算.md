# AdPrompt Studio — 成本核算

> 诚实口径：本项目总预算 ¥20，全部成本透明可核验。模拟数据与真实数据成本分开记录。

## 一、成本模型

**单次 LLM 调用成本** = 输入 tokens × 输入单价 + 输出 tokens × 输出单价

DeepSeek API 官方价（2026-08 参考）：
- 输入：¥2 / 1M tokens（缓存未命中）→ 保守均价 **¥1.5 / 1M**
- 输出：¥8 / 1M tokens → 保守均价 **¥6 / 1M**

**单次生成调用量估算**（六步工作流 + 质检）：
- 平均每次调用：输入 2,000 tokens + 输出 1,500 tokens
- 每次生成 ≈ 5 次调用（卖点/文案/视觉/分镜 + 质检），A/B 实验组 +2 次重写

**单次生成成本** = 5 × (2000×1.5 + 1500×6) / 1M = 5 × 0.012 = **¥0.06/次**

## 四、成本控制措施（面试讲法）

1. **RAG 本地化**：embedding 用 bge-small-zh 本地跑，零 API 成本
2. **模板规则化**：多模型适配用纯规则代码（不调 LLM），省 3 次调用
3. **质检低温度**：裁判温度 0.2（生成 0.7），稳定少重试
4. **重写止损**：自动重写 ≤2 轮，防成本无限上涨
5. **护栏监控**：A/B 实验设单次成本护栏 ¥0.1/次，超限否决

## 五、诚实局限

- 成本为**估算值**（事件表记录"生成次数"，未记每次调用精确 token 数）
- 精确计量需在 API 层记录 usage 字段（**已列为迭代项**）
- 模拟数据成本（¥6.78）是估算，不是真实账单；真实 API 消耗仅 ¥0.14
