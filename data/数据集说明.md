# AdPrompt Studio — 数据来源与 D1 数据管线说明

> 诚实红线：以下全部为**真实公开数据**（`is_simulated = 0`），来源可核验，成本 ¥0。

## 1. 数据集清单

| 数据集 | 来源 | 下载内容 | 用途 |
|---|---|---|---|
| EAVSD 电商广告视频分镜数据集 | [HuggingFace: zjyao-PKU/EAVSD](https://huggingface.co/datasets/zjyao-PKU/EAVSD) | 8 个 `metadata/category_a..h.parquet`（约 25MB） | 测试 case：真实电商广告分镜（1 case 含 8 个场景 prompt） |
| Seedance 2 提示词数据集 | [HuggingFace: GokuScraper/seedance-2-prompts-datasets](https://huggingface.co/datasets/GokuScraper/seedance-2-prompts-datasets) | `metadata.jsonl`（约 38MB） | RAG 知识库语料：2000+ 条带时间轴结构的官方风格 prompt |

**刻意不下载的内容**（省流量，本项目用不到）：
- EAVSD 的 `shards/*.tar`：视频原文件包，每个 200MB+，共 367 个。本项目只需要 prompt 文本做知识库，不需要视频本体。
- Seedance-2 的 `covers/`、`videos/`、`ref_images/`：图片/视频媒体文件，同理不需要。

## 2. 网络说明

国内直连 `huggingface.co` 超时，下载统一走镜像 `hf-mirror.com`
（脚本内硬编码 `MIRROR = "https://hf-mirror.com"`）。

## 3. 清洗规则

### EAVSD（目标 50 case）
1. 合并 8 个 category parquet（原始约 1.6 万行）
2. 过滤：`n_scenes_generated >= 1` 且至少 1 条非空 `scene_prompts`
3. **按 category 分层抽样** 50 个 case（8 类尽量均匀，避免抽成单品类）
4. 场景展开：每 case 的 `scene_prompts` 数组 → 独立场景行（为 D2 知识库按场景分块做准备）

### Seedance-2（目标 400 条）
1. 解析 `metadata.jsonl`（约 2000+ 条记录）
2. prompt 提取：`i18n.en.p` 为主（带 0-4s/4-9s 时间轴结构，知识价值最高），`raw_p` 兜底
3. 过滤：prompt 长度 < 50 字符丢弃
4. 按 prompt 内容 MD5 去重
5. **按 category 分层抽样** 400 条

## 4. 落库结构（data/adprompt.db）

| 表 | 说明 | 行数（目标） |
|---|---|---|
| `eavsd_cases` | case 级元数据（id/category/场景数） | 50 |
| `eavsd_scenes` | 场景级（case_id/scene_index/prompt） | ~400（50×8） |
| `seedance_prompts` | prompt 级（category/prompt/平台） | 400 |
| `data_sources` | 数据来源与抽样记录（诚实可溯源） | 2 |

所有表带 `is_simulated INTEGER DEFAULT 0` 字段——真实数据统一为 0，
后续 D7 模拟用户数据为 1，复盘报告按此区分「真实 vs 模拟」。

## 5. 复现

```bash
python scripts/download_data.py   # 幂等：已下载文件跳过
python scripts/clean_data.py      # 清洗 → 抽样 → 落库
```

下载清单（时间/来源/大小）见 `data/raw/download_manifest.json`。
